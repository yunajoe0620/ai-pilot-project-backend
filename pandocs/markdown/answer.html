-x2+4x≥x2-2x-8
0≥2x2-6x-8
0≥x2-3x-4
0≥(x-4)(x+1)
따라서, -1≤x≤4이다.
함수 h(x)=f(x)-g(x)=-2x2+6x+8.
함수 k(x)=|g(x)|=|x2-2x-8|=|(x-4)(x+2)|.
g(x)=0의 근은 x=-2,4이다.
g(x)는 아래로 볼록한 포물선이므로 -2<x<4에서 g(x)<0이고, x<-2 또는 x>4에서 g(x)>0이다.
범위 -1≤x≤4에서 함수 k(x)를 보면,
이 범위에서 -1≤x<4 일 때 g(x)≤0 이므로 k(x)=|g(x)|=-g(x)=-x2+2x+8 이다.
x=4 일 때 g(4)=0 이므로 k(4)=0이다.
따라서 -1≤x≤4 범위에서 k(x)=-x2+2x+8 이다.
k(x)=-(x2-2x)+8=-(x-1)2+1+8=-(x-1)2+9.

따라서 k(x)의 최댓값은 x=1일 때 k(1)=9이다.

주어진 방정식은 |x2-2x-3|=mx-m+2 이다.
y=|x2-2x-3|=|(x-3)(x+1)| 의 그래프와 y=mx-m+2=m(x-1)+2 의 그래프의 교점의 개수를 생각한다.
직선 y=m(x-1)+2는 항상 점 (1,2)를 지난다.
함수 y=|x2-2x-3|의 그래프를 그리자.
y=x2-2x-3=(x-1)2-4. 꼭짓점은 (1,-4), x절편은 -1,3.
y=|x2-2x-3|은 x축 아래 부분을 접어 올린 그래프이다. 꼭짓점은 (1,4)가 된다. (원래 꼭짓점이 접혀 올라감).
점 (1,2)는 y=|x2-2x-3| 그래프 위의 점 (1,|1-2-3|)=(1,4) 보다 아래에 있다.
직선이 점 (1,2)를 지나면서 회전할 때 교점의 개수가 4개가 되는 경우를 찾는다.
1) 직선이 y=-(x2-2x-3)=-x2+2x+3 (-1<x<3) 와 접할 때:
-x2+2x+3=m(x-1)+2
x2+(m-2)x-m-1=0
판별식 D=(m-2)2-4(-m-1)=m2-4m+4+4m+4=m2+8=0. 실수 m은 존재하지 않는다. 즉, (1,2)를 지나는 직선은 위로 볼록한 부분(-1<x<3)에 접하지 않는다.
2) 직선이 점 (-1,0)을 지날 때:
0=m(-1-1)+2=-2m+2, m=1. 이 때 교점은 3개 (x=-1에서 접하는 것이 아님).
3) 직선이 점 (3,0)을 지날 때:
0=m(3-1)+2=2m+2, m=-1. 이 때 교점은 3개.
4) 직선이 y=x2-2x-3 (x<-1 또는 x>3) 와 접할 때:
x2-2x-3=m(x-1)+2
x2-(m+2)x+m-5=0
판별식 D=(m+2)2-4(m-5)=m2+4m+4-4m+20=m2+24=0. 실수 m은 존재하지 않는다.
그래프를 그려보면, 점 (1,2)를 지나는 직선의 기울기가 m=-1 (점 (3,0) 통과) 보다 크고, m=1 (점 (-1,0) 통과) 보다 작을 때 교점은 4개가 된다.
즉, -1<m<1 일 때 서로 다른 네 실근을 가진다.
따라서 정수 m의 값은 0 뿐이다.
정답: 0
