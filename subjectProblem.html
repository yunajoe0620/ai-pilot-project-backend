[문제 1]. [난이도: 어려움] [유형: 서술형]

x 에 대한 이차방정식 x 2 - ( m - 3 ) x + m - 2 = 0 의 두 근이 모두 양의 정수가 되도록 하는 실수 m 의 값을 구하시오.

[문제 2]. [난이도: 어려움] [유형: 서술형]

정의역이 { x | 0 ≤ x ≤ 2 } 인 이차함수 f ( x ) = x 2 - 2 k x + k 2 + 1 의 최솟값을 g ( k ) 라고 할 때, - 1 ≤ k ≤ 1 에서 함수 g ( k ) 의 최댓값을 구하시오. (단, k는 실수)

[문제 3]. [난이도: 어려움] [유형: 서술형]

x 에 대한 이차방정식 x 2 - 2 ( k - 1 ) x + k 2 - 5 k + 4 = 0 이 한 근은 - 1 과 1 사이에 있고, 다른 한 근은 1 보다 크도록 하는 실수 k 값의 범위를 구하시오.

[문제 4]. [난이도: 어려움] [유형: 서술형]

x 에 대한 방정식 | x 2 - 2 x - 3 | = a 가 서로 다른 네 실근을 갖도록 하는 실수 a 값의 범위를 구하시오.

[문제 5]. [난이도: 어려움] [유형: 서술형]

이차함수 f ( x ) = x 2 - 4 a x + 4 a 2 + a 에 대하여, x ≥ a 인 범위에서 f ( x ) 의 최솟값이 10 이 되도록 하는 모든 실수 a 값의 합을 구하시오.
