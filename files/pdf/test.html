C+=2x3+2x2+x+3 ...(ㄷ)
(ㄱ) + (ㄴ) + (ㄷ) 을 하면

(ㄹ) - (ㄴ) 을 하면 A=(3x3+2)−(x3−3x2+4x−1)=2x3+3x2−4x+3

X*Y=2X−Y=4x2+8x−5 ...(ㄱ)

(ㄱ) ×2 를 하면 4X−2Y=8x2+16x−10 ...(ㄷ)
(ㄷ) + (ㄴ) 을 하면 (4X−2Y)+(2Y−X)=(8x2+16x−10)+(−x2−5x+2)

따라서 X=73x2+113x−83
(ㄴ) ×2 를 하면 4Y−2X=−2x2−10x+4 ...(ㄹ)
(ㄱ) + (ㄹ) 을 하면 (2X−Y)+(4Y−2X)=(4x2+8x−5)+(−2x2−10x+4)
